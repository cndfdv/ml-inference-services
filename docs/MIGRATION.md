# Переход к задаче / модели

| Прежняя папка | Новая папка |
| --- | --- |
| `asr-gigaam` | `asr/gigaam` |
| `ocr` с EasyOCR | `ocr/easyocr` |
| `embedder` | `embeddings/user-bge-m3` и `embeddings/e5-small` |
| `model-inference` | самостоятельные модели в `asr/`, `embeddings/`, `ocr/` |

Корневой `compose.yaml` включает файлы каждой модели. В каждой папке свой код
инференса и HTTP: обращения между моделями или общая очередь не используются.
Прежний универсальный `MODEL_NAME` заменён явным выбором модели.

У четырёх E5/USER/Rapid/Whisper сохранены модельные HTTP-ручки, порты,
checkpoint, precision и обработка входов. GigaAM/EasyOCR получили модельные
ручки; старые `/transcribe`, `/ocr` и `/health` продолжают работать как скрытые
алиасы. Прежние переменные их `.env` получили префиксы `GIGAAM_` и `EASYOCR_`;
сверьте настройки с шаблоном в папке модели. Старые имена GigaAM/EasyOCR
принимаются как резервные значения; новые имена имеют приоритет.

Для постоянного хранения по умолчанию используются отдельные Docker volumes.
Существующие готовые bundles переносятся целиком вместе с `manifest.json`,
без повторного скачивания или экспорта. На `home` миграция выполняется отдельно
от чужих Docker-проектов. `compose.local.yaml` позволяет подключить локальные
bind-каталоги вместо named volumes; этот файл исключён из Git.

Новый `run.sh` принимает путь папки: `asr/whisper`, `embeddings/e5-small` и т. п.
Для четырёх закреплённых моделей `PREPARE_MODE=auto` теперь скачивает отсутствующие
веса до старта HTTP, а `offline` требует уже подготовленный bundle.

Исходные реализации и прежняя структура сохранены в истории Git.
