# Техническая документация — GigaAM ASR

Сервис распознавания речи на GigaAM: модель в ONNX, инференс на CPU, запросы
обрабатываются по очереди одним воркером, модель выгружается из RAM по простою.

## Оглавление

| Документ | О чём |
|----------|-------|
| [architecture.md](architecture.md) | Как всё устроено: потоки, очередь, жизненный цикл модели, путь запроса, декод и чанковка аудио, память |
| [api.md](api.md) | HTTP-эндпоинты: что принимают, что возвращают, коды ошибок |
| [dataclasses.md](dataclasses.md) | Все dataclass'ы проекта: конфигурация, контракты API, единица работы воркера |

## Карта модулей

| Модуль | Роль | Подробности |
|--------|------|-------------|
| `app.py` | HTTP-слой (FastAPI): роуты, приём файла, ожидание результата | [architecture.md#путь-запроса](architecture.md#путь-запроса), [api.md](api.md) |
| `transcriber.py` | Поток-воркер: очередь, загрузка/выгрузка модели, инференс, чанковка | [architecture.md](architecture.md) |
| `config.py` | Конфигурация из env (`Settings`) + общий логгер | [dataclasses.md#settings](dataclasses.md#settings) |
| `schemas.py` | Типы тел ответов API для OpenAPI | [dataclasses.md#контракты-api](dataclasses.md#контракты-api) |
| `download_model.py` | Разовое скачивание модели с HuggingFace в кеш | [architecture.md#подготовка-модели](architecture.md#подготовка-модели) |

Быстрый старт, настройки `.env` и запуск — в корневом [../README.md](../README.md).
Здесь — то, что происходит внутри.
